# 📚 Estudo Fácil

Aplicação web simples para organizar tarefas de estudo, acompanhar atividades concluídas e visualizar o progresso.

## 🎯 Objetivo

Este projeto nasceu como uma oportunidade de transformar um repositório vazio em uma aplicação prática, demonstrando fundamentos de desenvolvimento web.

## ✨ Funcionalidades

- Adicionar tarefas de estudo;
- Classificar tarefas por matéria;
- Marcar tarefas como concluídas;
- Excluir tarefas;
- Limpar tarefas concluídas;
- Calcular automaticamente o percentual de progresso;
- Salvar os dados no navegador com `localStorage`;
- Layout responsivo para celular e computador.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- LocalStorage API
- GitHub Pages

## 📂 Estrutura

```text
├── index.html
├── style.css
├── script.js
└── README.md
```

## ▶️ Como executar

Abra o arquivo `index.html` no navegador.

Também é possível publicar o projeto pelo **GitHub Pages**.

## 🧠 O que pratiquei

Este projeto permite praticar manipulação do DOM, eventos, formulários, arrays, objetos, funções, armazenamento local e criação de interfaces responsivas.
